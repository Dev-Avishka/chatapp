# Chat App Backend

This is a simple backend implementation for a real time chat app with Go and JSON DB for the backend 
## Features
No Authnetication \
No Moderation \
Real Time Chat
## Technologies Used
- Go
- JSON DB
To deploy this project just run the buildanddeploy.sh on a linux env

```bash
chmod +x buildanddeploy.sh
./buildanddeploy.sh
```
