# Chat App Backend

This is a simple backend implementation for a real time chat app with Go and JSON DB for the backend 
## Features
No Authnetication \
No Moderation \
Real Time Chat
## Technologies Used
- Go
- JSON DB
To deploy this project just run the buildanddeploy.sh on a linux env

```bash
chmod +x buildanddeploy.sh
./buildanddeploy.sh
```

## Reason to Build this
Created and Configured my own hardware for a server running on Linux and wanted to check its capabilities, By allowing this to be public for several hours and letting the public use the site, and shut down when the server crashed
